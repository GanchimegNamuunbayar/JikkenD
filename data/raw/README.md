# Raw sequence data

Place downloaded NCBI files here (not tracked in git).

| Path | Content |
|------|---------|
| `protein/*.faa` | Proteome FASTA per species (e.g. `thaliana.faa`) |
| `genome/<species>/` | Genomic FASTA (e.g. `*.fna`) for `scripts/genome/dna_csv.py` |

See the [main README](../../README.md) for download links and workflow.
